# Storyclash

> Storyclash is an AI-powered influencer marketing software platform for brands and agencies to discover creators, analyze brand and competitor strategies, manage collaborations in a purpose-built CRM, and measure campaign performance and revenue ROI across Instagram, TikTok, YouTube, and Facebook. It exposes an enterprise REST API with token-based authentication and real-time webhooks that streams campaign KPIs, creator profiles, content performance, and revenue attribution as structured JSON into BI tools (Power BI, Tableau, Looker Studio). Headquartered in Linz, Austria; a Speedinvest portfolio company, since acquired by Kolsquare.

## APIs

- [Storyclash API](https://www.storyclash.com/integrations/api-integration): Enterprise REST API — token auth over HTTPS, structured JSON, real-time webhooks; campaign data (50+ KPIs) and bulk creator import. Base URL https://api.storyclash.com
- [API Documentation (Notion)](https://storyclash.notion.site/Storyclash-API-Documentation-1266dc2ddd0880a79cf9e3d34c19fa01): Endpoint specifications, JSON response examples, and integration guide.
